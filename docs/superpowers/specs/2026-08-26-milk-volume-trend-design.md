# 奶量趋势统计设计规格

## 背景与目标

在现有喂奶记录页面增加奶量趋势统计，帮助家人从不同时间尺度观察宝宝的奶量变化。统计必须保持当前“暖奶白、低打扰、单手可读”的产品气质，不影响现有快速记录流程。

## 已确认的用户体验

- 统计采用“今日总量摘要 + 趋势图”的组合布局。
- 趋势提供三个聚合粒度：按天、按周、按月。
- 按天展示近 90 天；按周展示近 12 周；按月展示近 12 个月。
- 默认打开按天视图，用户可以切换到按周或按月。
- 日/周/月共用同一张图和交互模型，只改变横轴粒度和数据范围。
- 颜色采用 B 方案：杏仁橙作为日常柱色，玫瑰珊瑚强调当前范围内的最高值；背景和文字继续遵循 `DESIGN.md` 的暖色规范。
- 统计卡片保留今日总量（ml）摘要；首页不加入复杂的大型图表，完整趋势放在历史记录入口内，避免挤压快速喂奶操作。
- 不新增独立的统计入口：沿用首页底部现有“历史记录”按钮；打开历史覆盖层后，趋势区位于顶部，原始记录列表继续位于趋势区下方。

## 统计口径

- 只有 `amount_ml` 为有效数值的喂奶记录计入奶量总量。
- 左乳/右乳等没有明确毫升数的记录不计入奶量总和，但仍计入喂奶次数等既有记录统计。
- “日”沿用项目的中国时间喂奶周期：每天 08:00 作为周期起点。现有 `getChinaCycleStart` 负责范围起点计算；聚合实现必须与该周期定义一致。
- “周”按中国时间自然周聚合，周一作为一周起点。
- “月”按中国时间自然月聚合。
- 当前范围内无有效毫升数的周期仍保留为 0，保证横轴连续，不因没有记录而跳点。
- 每个聚合点至少返回周期标签、奶量总和、喂奶记录总数和有毫升数记录数，便于图表无障碍文本和空状态说明。

## 架构与数据流

采用服务端聚合、客户端绘制：

1. 数据库层在 `src/storage/database/sqlite.ts` 增加奶量趋势查询，按房间、粒度和范围读取 `feed_records`，只聚合有效 `amount_ml`，并生成连续的周期点。
2. 新增 `src/app/api/rooms/[id]/feed-stats/route.ts` GET 接口，参数包含 `granularity=day|week|month` 和 `range`（分别限制为 90、12、12 的最大范围）。接口返回结构化序列和当前范围汇总；非法参数返回 400，房间不存在返回 404。
3. 客户端在 `src/app/page.tsx` 的历史覆盖层中维护当前趋势粒度、趋势数据、加载状态和错误状态。切换粒度时只请求对应聚合结果，不下载 90 天原始记录。
4. 图表使用项目已有的 `recharts` 与 `src/components/ui/chart.tsx` 基础设施；新增一个聚焦奶量趋势的组件文件，避免继续扩大 `page.tsx` 的职责。图表需要响应式宽度、明确的轴标签、中文 tooltip 和无数据空状态。
5. 历史日期范围按钮（7/14/30 天）保留给原始记录列表；趋势图的日/周/月切换独立存在，不改变列表加载范围。趋势请求应在历史覆盖层打开时启动，并用现有 `requestState.historyGate` 或独立趋势请求门控防止旧响应覆盖新选择。

## 界面行为

- 历史覆盖层顶部继续显示返回、标题和原始记录范围按钮。
- 在记录列表之前增加趋势区：今日总量摘要、日/周/月切换、图表和简短的周期说明。
- 首页只保留现有“次数 + 今日 ml”统计条，不新增大图表或独立“统计”按钮。
- 按天横轴使用短日期标签，按周使用周起始日期，按月使用“YYYY年M月”；标签过多时减少显示密度但不删除数据点。
- tooltip 展示周期、总奶量、喂奶次数和有奶量记录次数。
- 最大值柱使用玫瑰珊瑚；没有数据时显示暖色空状态和“暂无可统计奶量”，不显示误导性的 0ml 总量。
- 记录列表加载失败时沿用现有错误提示；趋势接口失败时在趋势区单独显示错误，并提供重试入口，不清空已加载的原始记录列表。
- 视图切换按钮使用明确的选中态、可触摸尺寸和 `aria-pressed`，不引入额外复杂交互。

## 边界与兼容性

- 现有首页今日统计、快速记录、历史原始记录列表、删除刷新逻辑保持不变。
- 现有 API 的 `days` 最大值仍可保持 30；趋势接口使用自己的粒度和范围约束，不扩大原始记录接口的响应负担。
- 所有时间格式化必须在客户端稳定执行，避免服务端渲染阶段读取动态浏览器时间造成 hydration 不一致。
- 统计查询需要覆盖没有 `amount_ml` 的旧数据，不修改数据库 schema，不回填历史记录。
- 图表在窄屏下不得产生横向溢出；长周期横轴可通过标签抽样和 tooltip 保持可读。

## 测试与验收

- 数据库测试：按天/周/月聚合、08:00 周期边界、跨月/跨年、无奶量记录、连续 0 周期。
- API 测试：合法粒度和范围、非法参数、房间不存在、返回字段稳定性。
- 组件/页面测试：默认按天、切换粒度触发请求、错误和空状态、最高值强调色、`aria-pressed` 选中态。
- 回归测试：运行现有测试、`pnpm run ts-check`、`pnpm run lint:build` 和生产构建。
- 浏览器验证：检查桌面和移动宽度下历史覆盖层，确认日/周/月切换、tooltip、图表加载/错误/空状态以及现有喂奶记录流程不受影响。

## 非目标

- 不根据左乳/右乳时长估算毫升数。
- 不增加预测、目标线、医学建议或跨房间比较。
- 不重做首页快速记录区域或引入新的导航结构。
