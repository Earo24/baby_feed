# 多记录趋势图设计规格

## 背景

当前历史记录入口已经提供奶量趋势图，并支持按天、按周、按月查看较长时间范围。用户希望在同一张趋势图中同时看到便便、吃药、辅食和清醒记录，但这些记录的单位和奶量不同，不能直接共用同一条数值轴。

本设计在不改变现有奶量趋势主体验的前提下增加事件概览，并明确使用产品的浅色暖色主题，避免系统深色模式或视觉伴侣外框造成颜色误判。

## 目标

1. 奶量继续作为唯一的主趋势指标，保持现有按天 / 按周 / 按月切换和长跨度范围。
2. 在每个时间周期对应的奶量柱上方，用事件点提示便便、吃药、辅食、清醒是否发生。
3. 通过 tooltip 展示事件实际次数；清醒额外展示累计清醒时长。
4. 图表卡片、控件和 tooltip 固定使用浅色产品主题，不依赖系统深色模式。
5. 新增和删除记录后，趋势图能随现有刷新机制更新。

## 非目标

- 不把五类记录绘制成五条共用纵轴的折线。
- 不把事件次数转换成与 ml 可比较的数值。
- 不新增独立的统计页面或新的导航入口，继续放在历史记录入口内。
- 不改变便便、吃药、辅食、清醒的记录表单和记录列表样式。

## 视觉与布局

### 卡片与主题

- 页面背景：`#FFF9F2`
- 图表卡片：`#FFFCF8`
- 浅色控件底：`#FFF3E6`
- 主文字：`#3D3229`
- 次要文字：`#8B7E74` / `#A89888`
- 网格线和边界：`#EDE5DC`
- 图表不使用 `.dark` 主题变量来决定背景、tooltip 背景或主要文字颜色；即使系统为深色模式，产品卡片仍保持暖奶白浅色表面。

### 奶量柱

- 普通周期柱：`#E3B87A`
- 当前可见范围内总奶量最高的周期：`#D9917A`
- 奶量单位保持 `ml`。
- 柱子圆角、坐标轴、网格线和现有奶量趋势图一致。

### 事件点

每种事件使用一个固定颜色和固定事件轨道，颜色沿用记录页：

| 记录项 | 颜色 | 统计信息 |
| --- | --- | --- |
| 便便 | `#B8A08A` | 周期内记录次数 |
| 吃药 | `#8B9EAF` | 周期内记录次数 |
| 辅食 | `#6F9B78` | 周期内记录次数 |
| 清醒 | `#7BAF8E` | 周期内记录次数 + 累计时长 |

事件点按固定轨道排列，避免多个类别或同一日期的点互相覆盖。一个周期内某类事件至少有一条记录时显示该类一个点；具体次数不通过点的数量编码，而在 tooltip 中展示。

图表下方提供颜色图例：便便、吃药、辅食、清醒。图例只解释颜色，不承担筛选功能。

## 交互

1. 保留现有粒度切换：按天、按周、按月。
2. 保留现有范围：按天 90 天、按周 12 周、按月 12 月。
3. 鼠标悬停或触摸某个周期时，tooltip 显示：
   - 周期标签；
   - 总奶量和有奶量记录的喂奶次数；
   - 有记录的事件类别及次数；
   - 清醒累计时长（有清醒记录时）。
4. 没有奶量但有其他事件的周期仍保留在横轴上；该周期没有柱高，但事件点仍可被查看。
5. 没有任何可统计记录时显示空状态，不显示误导性的零值趋势。
6. 加载失败沿用现有错误提示和重试入口。

## 数据与 API

### 周期口径

- 继续使用现有北京时间周期计算。
- 按天以北京时间 08:00 为周期起点。
- 先按北京时间 08:00 将每条记录归入业务日，再以该业务日计算周（周一）和月（每月 1 日）周期。
- 按周以北京时间周一为周期起点，按月以北京时间每月 1 日为周期起点。

### 响应结构

扩展现有房间趋势统计接口，使每个 `points` 项除现有奶量字段外，包含事件统计：

```ts
type TrendEventCounts = {
  poop_count: number;
  medication_count: number;
  solid_food_count: number;
  awake_count: number;
  awake_minutes: number;
};

type MultiRecordTrendPoint = {
  period_start: string;
  label: string;
  total_ml: number;
  feed_count: number;
  measured_count: number;
  events: TrendEventCounts;
};
```

接口一次按房间和粒度读取五类记录，再使用同一套周期键聚合，避免客户端分别请求五个接口导致不同步。现有奶量字段保持兼容，已有只读取奶量字段的调用不应被破坏。

### 数据规则

- 便便、吃药、辅食：每条记录计数 1。
- 清醒：每条已结束记录计数 1，并累加 `ended_at - started_at` 的分钟数。
- 无效时间、负时长或超出请求范围的记录忽略。
- 没有 `ended_at` 的进行中清醒记录不纳入趋势统计；它仍按现有首页的“当前清醒”逻辑展示。

## 组件边界

- 统计聚合逻辑放在 `src/lib`，保持纯函数，便于单元测试。
- SQLite 查询继续集中在 `src/storage/database/sqlite.ts`，API 路由不直接创建连接。
- API 路由负责校验房间、粒度和范围，并返回统一趋势点。
- 趋势组件负责颜色、柱子、事件轨道、tooltip、图例和加载/错误/空状态，不负责数据库细节。
- 页面只负责传入房间 ID、今日奶量和刷新键，并在记录增删后触发趋势刷新。

## 错误与兼容

- 房间不存在、参数非法、数据库异常沿用现有 API 错误格式。
- 某一类事件表查询失败时，整个统计请求失败并显示重试，避免展示部分类别造成误解。
- 旧数据中缺少可选字段时按 0 处理，不阻塞奶量统计。

## 可访问性与响应式

- 趋势粒度按钮保留 `aria-pressed` 和分组标签。
- 图例文字同时显示，不仅依赖颜色；事件点的 tooltip 文字必须包含类别名称和数量。
- 手机窄屏时横轴标签继续按现有抽样规则减少密度，事件轨道不改变柱子的可点击区域。
- 颜色对比保持与暖白背景的可读性，最高值柱与普通柱不能只靠颜色差异表达，tooltip 仍显示完整数值。

## 测试与验收

### 单元测试

- 按天、周、月的周期键和北京时间 08:00 边界。
- 五类记录分别聚合到正确周期。
- 清醒分钟数累加、无效时间和负时长过滤。
- 空周期保留，事件存在但奶量为 0 的周期可正常返回。

### 组件/API 测试

- 粒度和范围参数校验。
- tooltip 同时显示奶量和事件统计。
- 新增、删除记录后刷新键更新趋势。
- 加载中、错误重试、无数据状态。

### 验收标准

- 历史记录入口内能看到统一的多记录趋势图。
- 按天 / 周 / 月都能看到长跨度奶量柱和事件点。
- 事件点不与奶量共用数值纵轴，且 tooltip 能读到实际次数。
- 产品页面在系统深色模式下仍保持暖奶白图表卡片和已确认的 A 配色。
- 既有奶量趋势和历史记录功能测试全部通过。
